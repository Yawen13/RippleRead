## 🎯 问题分析

### 原始问题 ❌
```
首屏显示布局：
✓ 欢迎 + 搜索栏           (可见)
✓ 继续阅读 + 今日目标     (可见)
⚠️ 推荐书籍               (部分被截断)
⚠️ 每日文章               (底部被截断)
❌ 阅读洞察               (完全隐藏，需滚动)

存在问题：
- 内容拥挤，占用空间过大
- 用户无法一屏内了解全貌
- 版面出现变形和不适当的换行
```

### 解决方案 ✅
通过以下策略实现一屏完整显示：

1. **卡片紧凑化** - 减少卡片宽度和内边距
2. **间距优化** - 精细调整所有间距和 margin
3. **网格调整** - 改变文章和统计的网格布局
4. **内容精选** - 显示最相关的文章（3 篇 → 2 篇）
5. **字体微调** - 保持可读性的前提下缩小字体

## 🔧 核心改动清单

### 1. 页面布局层级 (`.dash-page`)
```css
padding: 22px 28px 40px
    ↓
padding: 18px 24px 32px        /* 减少约 5% */
```

### 2. 网格间距 (`.dash-grid`, `.articles-grid`, `.stats-capsule`)
```css
gap: 14px → 12px               /* -2px，-14% */
margin-bottom: 14px → 10px     /* -4px，-29% */
```

### 3. 卡片尺寸优化
```
继续阅读:   padding 14px 16px → 12px 14px
今日目标:   min-height 218px → 180px (-17%)
推荐卡片:   width 220px → 180px (-18%)
文章卡片:   thumb 80x80 → 70x70 (-13%)
```

### 4. 网格列数调整
```
文章网格:   repeat(3, 1fr) → repeat(2, 1fr)
统计网格:   repeat(4, 1fr) → repeat(2, 1fr)
```

### 5. 内容数量减少
```
每日文章:   显示 3 篇 → 显示 2 篇
```
