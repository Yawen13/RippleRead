# ✅ 主页 UI 优化 - 使用说明

## 🎯 问题已解决

**原因**: CSS 文件有版本号缓存控制，浏览器使用的是旧版本

**解决**: 已更新版本号，强制浏览器重新加载最新 CSS 和 JS

## 📋 操作步骤

### 方法 1️⃣: 完全清除缓存（推荐）

#### Windows 操作步骤：

1. **关闭浏览器** 中所有 RippleRead 标签页
2. **清除浏览器缓存**:
   - Chrome: 按 `Ctrl + Shift + Delete`
   - Firefox: 按 `Ctrl + Shift + Delete`
   - Edge: 按 `Ctrl + Shift + Delete`
   - Safari: 菜单 → 开发 → 清空缓存
3. **选择**:
   - 时间范围: "一切时间" 或 "全部"
   - 勾选: ✓ Cookie和网站数据
   - 勾选: ✓ 缓存的图片和文件
4. **点击** "清除数据" 或 "删除"

#### 步骤 2: 启动应用

**选项 A - 双击批处理文件（最简单）**:
```
e:\RippleRead\RippleRead\run_server.bat
```
- 会自动启动服务器
- 看到 "Uvicorn running on..." 表示启动成功

**选项 B - 命令行启动**:
```bash
cd e:\RippleRead\RippleRead
python start_server.py
```

#### 步骤 3: 打开浏览器

1. 打开浏览器
2. 访问 `http://127.0.0.1:8001`
3. **重要**: 按 `Ctrl + F5` 执行"强制刷新"（清除缓存并重新加载）

### 方法 2️⃣: 快速查看（仅清除网站缓存）

如果您不想清除所有浏览器数据：

1. 打开应用: `http://127.0.0.1:8001`
2. 按 `Ctrl + F5` (Windows) 或 `Cmd + Shift + R` (Mac) **强制刷新**
3. 页面应立即显示新布局

## 🆘 如果仍然没有变化

### 问题排查

#### 1. 验证文件是否已修改
```bash
# 在项目目录运行
type home.css | findstr "width: 180px"  # 应该找到推荐卡片宽度
```
预期输出应包含 `width: 180px;`

#### 2. 检查浏览器开发者工具
1. 按 `F12` 打开开发者工具
2. 进入 "Network" 标签
3. 刷新页面 (`Ctrl + F5`)
4. 查看 `home.css` 和 `home.js`:
   - 应该显示 `home.css?v=7`
   - 应该显示 `home.js?v=5`
   - 状态码应该是 200（不是 304）

#### 3. 完全重启
```bash
# 1. 关闭所有浏览器窗口
# 2. 关闭 Python 服务器 (Ctrl + C)
# 3. 等待 5 秒
# 4. 重新启动服务器: python start_server.py
# 5. 打开浏览器
# 6. 清除缓存 (Ctrl + Shift + Delete)
# 7. 访问 http://127.0.0.1:8001
# 8. 强制刷新 (Ctrl + F5)
```

#### 4. 检查是否是其他应用占用端口
```bash
# Windows 命令行：
netstat -ano | findstr :8001
# 或
lsof -i :8001
```
