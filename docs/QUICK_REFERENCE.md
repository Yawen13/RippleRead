## 🎨 关键改动一览

### 1️⃣ 卡片紧凑化
```css
/* 推荐书籍 */
.recs-card {
  width: 220px → 180px;           /* 更窄 */
  padding: 18px → 12px;           /* 更紧 */
}

/* 文章 */
.article-card__thumb {
  80x80px → 70x70px;             /* 更小 */
}

/* 今日目标 */
.goal-ring {
  92x92px → 78x78px;             /* 更小 */
}
```

### 2️⃣ 网格调整
```css
/* 文章网格 */
.articles-grid {
  grid-template-columns: repeat(3, 1fr) 
  → grid-template-columns: repeat(2, 1fr);
}

/* 统计网格 */
.stats-capsule {
  grid-template-columns: repeat(4, 1fr)
  → grid-template-columns: repeat(2, 1fr);
}
```

### 3️⃣ 间距优化
```css
/* 全局间距缩小 */
gap: 14px → 12px;              /* -2px */
margin: 22px → 18px;           /* -4px */
padding: 24px → 20px;          /* -4px */
```

### 4️⃣ 字体微调
```css
/* 标题 */
font-size: 0.72rem → 0.66rem;
font-size: 0.68rem → 0.62rem;

/* 副文本 */
font-size: 0.58rem → 0.52rem;
font-size: 0.5rem → 0.46rem;
```

### 5️⃣ 内容精选
```javascript
// 每日文章
Math.min(articles.length, 3) → Math.min(articles.length, 2)
// 显示 3 篇 → 显示 2 篇
```

## ⚡ 快速故障排除

### 问题 1: 显示不对
**解决**: 清除浏览器缓存
```
Ctrl+Shift+Delete → 清除所有 → 确定
```

### 问题 2: 移动端布局错乱
**解决**: 检查视口设置
```html
<meta name="viewport" content="width=device-width, initial-scale=1.0">
```

### 问题 3: 推荐卡片溢出
**解决**: 无需操作，已通过 `flex-shrink: 0` 控制

### 问题 4: 文字太小
**解决**: 这是设计目标，字体仍保持可读

### 问题 5: 需要回滚
**解决**: 恢复 `home.css.backup` 和 `home.js.backup`
