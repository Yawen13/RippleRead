
## 关键改进点

### 1️⃣ 空间利用率提升
- 从 4-5 个视口高度 → 2-2.5 个视口高度
- 减少用户滚动操作
- 一屏内显示关键信息

### 2️⃣ 视觉焦点清晰
```
优先级排序：
1️⃣ 继续阅读 + 今日目标    (最重要)
2️⃣ 推荐书籍              (次重要)
3️⃣ 每日文章              (补充内容)
4️⃣ 阅读洞察              (参考数据)
```

### 3️⃣ 保持高保真设计
- ✅ 字体权重不变
- ✅ 配色方案完整
- ✅ 交互动画保留
- ✅ 品牌辨识度不降

### 4️⃣ 内容精选
- 推荐书籍：保留滚动（无限探索）
- 每日文章：显示 2 篇最相关
- 阅读统计：2x2 核心指标
